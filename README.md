# 领客海外 · 留学路线指南

独立撰写的中文留学信息静态网站，无需安装依赖。2026 年 11 月 7 日版包含 94 条路线与政策说明、71 个主题、159 个不同官方来源。

## 查看网站

直接打开 `index.html`，或在本目录运行 `python3 -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。

- 首页按国家/地区、学习阶段、路线类型和主题章节筛选，也能搜索正文、关键事实、申请步骤和来源名称。
- `topics.html` 是完整主题索引；`routes/` 中每个条目都有独立阅读页及来源记录，不依赖 JavaScript。
- 收藏保存在当前浏览器，更换设备或清除浏览器数据后不会同步。
- 已截止、暂停、停收、国别限制等状态会按官方资料注明；主题覆盖不表示所有项目正在接受申请。

## 修改内容

`data.js` 的每个对象是一条记录：

| 字段 | 用途 |
|---|---|
| `id` | 稳定编号，改内容时保留，避免已有链接和收藏失效 |
| `title`、`country`、`stage`、`type` | 标题及筛选条件；多阶段以中文顿号 `、` 分隔 |
| `cost`、`description`、`details` | 费用提示、简介及详细条件；金额写明适用年度 |
| `status` | 项目状态或适用轮次，不确定时不能写成申请开放 |
| `facts`、`steps` | 关键事实及申请/核对步骤，可选的字符串数组 |
| `source`、`sourceLabel` | 主要官方来源及名称 |
| `sources` | 多个来源组成的数组，每项为 `{"label":"名称","url":"https://…"}` |
| `verifiedDate` | 实际核查日期，格式为 `YYYY-MM-DD` |
| `auditTopics` | 对应主题编号数组，与 `topics.json` 里的主题关联 |
| `key` | 部分新增条目的内部稳定键，通常不用修改 |

修改数据或主题后，在本目录运行：

```sh
python3 build-pages.py
```

脚本会同步更新所有独立阅读页及主题索引。首页直接读取 `data.js`，无需构建。新加条目使用未占用的数字编号；已有编号不要重新排序。修改全站核查日期时，同步首页页尾和说明，但不要把未重新核实的条目标记为已核实。

## 发布到 GitHub Pages

1. 将本目录完整上传到 GitHub 仓库根目录，必须保留 `routes/` 子目录、`topics.html`、`index.html`、`style.css`、`app.js` 和 `data.js`。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，分支选 `main`，目录选 `/ (root)` 后保存。
3. 等 GitHub 给出网站地址后，检查首页、主题索引和独立条目。`.nojekyll` 可让 Pages 按静态文件直接发布；`build-pages.py`、`topics.json` 和本说明文件可一并保存以便维护。

本目录包含网站源文件和已生成的静态页面。第三方完整 PDF/指南没有复制进网站，来源按钮直接链接官方原件。

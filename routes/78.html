美国 CSS Profile：筛选接受国际生财务资料的院校

美国本科、硕士院校及其他资助
2027–28 名单

College Board 公布逐学年的参与院校表，其中单列是否对国际申请者使用 CSS Profile。

费用与资助
CSS Profile 是资助申请表，不是奖学金

申请条件与注意事项

查看 2027–28 名单的 International Students 栏，再到目标院校核对本人学位和入学轮次的要求。Yes 只表示该机构或项目使用此表，不表示对每位国际生给资助、保证全额需求或采用 need-blind 录取；No 也不排除院校使用其他表格。

关键事实

  • 所查 2027–28 表中，Amherst、Brown、Harvard College、Cornell 与 Columbia College and Engineering 的国际生栏均为 Yes；仍须逐校核对本人项目与资助政策。
  • 系统收集家庭收入、资产与支出，可填本地货币；院校可能另要求非同住家长资料或 IDOC 文件。
  • 应逐校确认截止日、费用减免和补件办法，不把 CSS 与 FAFSA 联邦资助混同。

如何申请 / 核对

  1. 在参与院校表核对学校及具体项目
  2. 在学校财务援助官网确认国际生资格和截止日
  3. 准备家庭财务资料，按要求提交 CSS 与附加文件
